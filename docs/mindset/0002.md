This is an important design pattern:

> Use a fast algorithm normally, but have a fallback when its assumptions begin failing.

Example:

Introsort starts with Quick Sort:

```
Quick Sort
     ↓
monitor recursion depth
     ↓
too deep?
     ↓
Heap Sort
```

Heap Sort guarantees:

```
O(n log n)
```

So Introsort combines:

```
Quick Sort's average performance
+
Heap Sort's worst-case guarantee
```
