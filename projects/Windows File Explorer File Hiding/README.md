# Windows File Explorer File Hiding
The requirement is to develop a Windows program that hide every file with the `.hideme`  extension from File Explorer.

| Requirement        | Description                                                  |
| ------------------ | ------------------------------------------------------------ |
| Target files       | All files endinding with `.hideme`                           |
| Target Application | Windows File Explorer                                        |
| Windows Version    | Build 7601 - 26300                                           |
| Architucture       | IA-32(x86) and AMD64(x64)                                    |
| Independence       | Must work regardless of Windows Explorer visibility settings |
| Stability          | No Explorer crashes or functionality problems                |
| Dependencies       | Third-party libraries and AI tools are permitted             |
| Deliverables       | Source code and comprehensive technical report               |
